# 统一数据结构与接口（阶段一）

> 本文档定义 A 模块对 B（编队）、C（遥测）暴露的统一数据结构和坐标转换接口。
> 阶段一只落地 `common/` 数据模型与 `CoordinateTransformer`，尚未改动 ORCA 核心、
> `automatic_mode.py` 或现有飞行控制逻辑。

> 阶段二之后的跨进程通信、生命周期和控制权规范见 [`多机通信与控制协议.md`](多机通信与控制协议.md)。本阶段一文档中的模型示例保留历史形式；跨进程命令必须增加 `CommandLifecycle`。

## 0. 统一坐标约定

所有内部算法统一使用 **World NED**：

| 轴 | 方向 |
|---|---|
| +X | North / 前 |
| +Y | East / 右 |
| +Z | Down / 下 |

- `VehicleState`、`FormationCommand`、`CollisionPrediction`、`ORCA`、`SafetyFilter`、
  `AvoidanceCommand`、`TelemetryMessage` 一律 World NED。
- **只有**最终 AirSim Adapter / Controller 层做坐标转换；A/B/C 不得各自转换。

## 1. 数据模型（`common/models.py`）

### `VehicleState`
- 从 `models/vehicle_state.py` **re-export**（单一来源，不复制、不搬迁）。
- 既有导入路径 `from models.vehicle_state import VehicleState` 不变；
  新代码可用 `from common.models import VehicleState`，两者是同一个类对象。

### `FormationCommand`（B → A）
B 只输出期望目标/期望速度，禁止直接调 AirSim 控制 API。

```python
@dataclass
class FormationCommand:
    vehicle_name: str
    mode: str = "velocity"                 # "position" | "velocity"
    target_position_ned_m: Vec3 = (0,0,0)  # mode="position" 时使用（World NED）
    desired_velocity_ned_mps: Vec3 = (0,0,0)  # mode="velocity" 时使用
    valid: bool = True
    priority: int = 50                     # 低于 safety/avoidance
    formation_id: str = ""
    timestamp_s: float = 0.0
```

### `AvoidanceCommand`（APF/ORCA/recovery 汇入 A）
```python
@dataclass
class AvoidanceCommand:
    vehicle_name: str
    desired_velocity_ned_mps: Vec3 = (0,0,0)  # World NED
    source: str = "none"
    valid: bool = True
    reason: str = ""
    priority: int = 100
```

### `TelemetryMessage`（A → C）
C 只读，不得修改飞行控制状态。
```python
@dataclass
class TelemetryMessage:
    timestamp_s: float
    vehicles: Dict[str, VehicleState] = field(default_factory=dict)
    avoidance: Optional[AvoidanceCommand] = None
    formation: Optional[FormationCommand] = None
    coordination_state: str = "monitor"   # monitor / yield / orca / hold
    valid: bool = True
```

### 校验规则
- `vehicle_name` 必须为非空字符串。
- 位置/速度向量必须为 3 分量且有限（拒绝 NaN/Inf）。
- `mode` 只能是 `"position"` / `"velocity"`，且对应字段必须存在。

## 3. 坐标转换（`coordination/coordinate_transform.py`）

保留现有 spawn/marker 偏移方案，新增可选旋转与 fail-closed 验证。

```python
class CoordinateTransformer:
    def __init__(self, spawn_offsets, rotations=None, require_validation=True): ...
    def to_common_ned(self, vehicle_name, local_ned) -> Vec3: ...       # R @ v + t
    def from_common_ned(self, vehicle_name, common_ned) -> Vec3: ...    # R^T @ (v - t)
    def to_common_velocity(self, vehicle_name, local_velocity) -> Vec3: ...  # R @ v
    def from_common_velocity(self, vehicle_name, common_velocity) -> Vec3: ...  # R^T @ v
    def set_rotation(self, vehicle_name, rotation) -> None: ...
    def validate(self, client, vehicle_names=None, markers=None, *, ...) -> CoordinateTransformValidation: ...
```

- 单位换算公式：`common = R @ home + t`；速度只旋转（平移不改变速度）。
- 单位旋转（identity）时与现有 `collision_predictor.to_common_ned` 完全一致。
- 便捷构造：`from_settings_json()` / `from_scene_markers()`（复用 `collision_predictor`
  的 `load_spawn_offsets` / `load_scene_marker_offsets`）。

### `validate()` 校验内容（fail-closed）

对每架无人机：
1. 校验旋转矩阵是**正交且 det=+1** 的合法旋转。
2. **位置**：`to_common_ned(getMultirotorState().position)` 与 `simGetObjectPose(vehicle).position`
   的实际全局位姿对比，误差 ≤ 容差。
3. **速度**：合法旋转必保持速度模长且可往返（`to_common_velocity` → `from_common_velocity`）。
4. **朝向**：记录各机 yaw（覆盖「不同初始朝向」）；提供 `markers` 时检查生成标记朝向，
   若标记被旋转且未配置旋转矩阵 → 判定需补旋转矩阵并 **fail-closed**。

- 任何一架未通过 → `validated=False`，`to_common_ned` 等抛 `CoordinateTransformUnvalidated`，
  未经确认的坐标转换结果**不得使用**。
- `client` 需提供 `getMultirotorState(name)` 与 `simGetObjectPose(name)`；单测注入 fake。
